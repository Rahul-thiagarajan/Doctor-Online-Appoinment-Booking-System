Common Issues & Troubleshooting

Login Issues

  • • Check your internet connection
  • • Verify your username and password
  • • Clear browser cache and cookies
  • • Try using a different browser
  • • Contact support if password reset is needed

Data Loading Problems

  • • Refresh the page (Ctrl+F5 or Cmd+R)
  • • Check server status on dashboard
  • • Ensure stable internet connection
  • • Try logging out and back in
  • • Report persistent issues to technical support

Report Generation Errors

  • • Verify date ranges are valid
  • • Check if data exists for selected criteria
  • • Ensure sufficient system resources
  • • Try generating smaller date ranges
  • • Contact support for large dataset exports

System Performance Issues

  • • Close unnecessary browser tabs
  • • Clear browser cache regularly
  • • Check system requirements compatibility
  • • Update browser to latest version
  • • Report chronic slowdowns to IT support
